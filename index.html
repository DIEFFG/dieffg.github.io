Import from TTCF Star Exam Spreadsheet

This reads directly from STAR_1, STAR_2, and STAR_3 sheets — the same format used in the TTCF Training Department compilation file.

1
Open your TTCF Excel file The file with STAR_1, STAR_2, STAR_3 sheets
2
Copy each sheet into this Google Spreadsheet Right-click the sheet tab → "Copy to" → this spreadsheet, OR copy-paste all data keeping the sheet names STAR_1, STAR_2, STAR_3
3
Click "Run TTCF Import" below All 3 sheets will be processed. Duplicates are automatically skipped.

Expected TTCF format:

SERREG NORANKLAST NAMEFIRST NAMEBNUNITSTAR LEVELDRUMCSAAFCATACHIEVED
129097PVTGREAVESJAYDON1TTCFBSS1P
229123PVTDRIGGSTRISTAN1TTCFALPHA1PPPPP
  • Star 3 sheets may omit the SAA column — handled automatically
  • Header variations (SURNAME vs LAST NAME, REG. NO. vs REG NO) are handled
  • Lowercase p is treated the same as P
  • SER and ACHIEVED columns are ignored

Import from Standardized Sheet

Use the "Star Exam Import" sheet with standardized headers for custom or reformatted data.

REG_NORANKLAST_NAMEFIRST_NAMEBNUNITSTAR_LEVELDRUMCSAAFCAT
29097PVTGREAVESJAYDON1TTCFBSS1P
27277SGTCHARLESKENTON1TTCFBRAVO3PPPP
  • STAR_LEVEL: 1, 2, 3, 4, or MC (Master Cadet)
  • Enter P for Pass, leave blank for not passed
  • Duplicates (same REG_NO + STAR_LEVEL) are skipped
